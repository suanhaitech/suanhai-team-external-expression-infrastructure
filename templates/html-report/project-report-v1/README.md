# 项目汇报模板 v1

状态：`implemented / experimental`

这是一个面向项目概览、阶段进展和对外汇报的静态 HTML 模板。它以 Start Bootstrap Agency 7.0.12 的单页响应式布局为上游参考，在固定提交基础上改造成中文、无远程运行依赖的项目表达起点。

## 使用方式

1. 将本目录复制到消费端仓库的任务作品目录，例如 `works/<任务编号>/v001/`。
2. 只修改 `index.html` 中带有 `data-slot` 属性的内容和页面导航文字；按任务范围决定是否保留各章节。
3. 保留 `styles.css` 和 `report.css`，除非任务明确记录了样式改造原因。
4. 将项目事实、图表和图片替换为任务中登记且获准使用的来源，不把模板中的占位文字当作项目事实。
5. 通过浏览器直接打开 `index.html` 检查离线状态，再进入任务的 review 阶段。

## 结构约定

- 顶部导航：页面章节锚点，适合较长的单页汇报。
- 首屏：说明项目名称、阶段和当前需要读者理解的核心判断。
- 事实摘要：放 2 至 4 个可追溯指标，不填无法定位来源的数字。
- 进展与下一步：分别说明已经完成、当前判断和下一步行动。
- 证据与边界：说明来源、已确认内容和仍待核验的部分。

## 边界

- 本目录只提供结构和样式，不包含任何项目事实、客户资料或发布授权。
- 进入 `manifest.yml` 只表示模板入口已经存在并通过基础检查，不表示页面内容已经专业验收。
- 模板来自固定的上游提交，不能在消费端让 submodule 自动跟随上游更新。
- 模板使用和页面修改都留在消费端仓库；不要把项目内容回写到基础设施仓。
- 模板依赖记录在 `template.yml`；当前运行时不依赖 CDN、远程字体、远程图片或远程接口。
