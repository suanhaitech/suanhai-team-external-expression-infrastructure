# HTML 任务 Harness

状态：`planned / not implemented`

本目录原计划存放 HTML 任务 Harness。消费端 HTML 制作的流程协议现由 [`workflows/html-production/`](../../workflows/html-production/ENTRYPOINT.md) 承载，并在 Manifest 中注册为 `expression.html-production`。

该 Harness 目录仍未实现独立执行器，也没有单独加入 Manifest。不要把本目录或其中的计划当成额外能力。

自动物料生成、本地浏览器预览、数学公式渲染和自动化多视口/无障碍检查仍未实现。当前工作流会要求 Agent 如实说明检查缺口，并由消费端现有任务工具记录单文件或自包含目录产物。
