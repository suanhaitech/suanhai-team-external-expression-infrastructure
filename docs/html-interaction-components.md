# HTML 交互组件

页面模板承载内容结构与样式，交互组件提供阅读操作，两者分别维护，最终由物料化器组合。这里的交互组件指按钮、选择器、导航和阅读器；`components/` 下的语义片段是另一种内容资产。

## 直接体验

打开 [交互体验页](../infrastructure/html/runtime-kits/preview/index.html)。这是不含项目资料的通用演示，直接引用真实运行时和容器脚本，不维护另一套演示实现。支持直接打开本地 HTML，也可在仓库根执行 `python -m http.server 8000 --bind 127.0.0.1` 后访问 `http://127.0.0.1:8000/infrastructure/html/runtime-kits/preview/`。

体验页有三页：第一页操作控制栏，第二页打开原图，第三页查看公式与输出。它是文档预览，不是新增的 Manifest capability。

## 默认装配

`html.materialize` 的 `DEFAULT_RUNTIME_KITS` 明确列出工具栏/公式包和原图阅读器。省略运行时参数仍装配这两个包；重复参数去重，其他已注册包增量加入。最终集合记录在 dry-run、`report.yml` 与 `materialization.json`。未登记、资源不完整或模板插槽不兼容时失败，不能悄悄漏装。

演示稿容器把比例、备注和运行时工具组合为底部悬浮栏；长页继续使用独立工具栏。小屏保留动作文字、44px 高触控目标；控制栏换行、备注展开或字体改变后重新测量，为正文预留滚动空间。原图阅读器默认就绪，Agent 应为真实原图添加入口；没有图片时不制造空按钮。

演示稿全屏时底栏持续隐藏并不可聚焦，鼠标/触摸下沿和Tab不再唤出；进入时收起备注，键盘翻页继续可用。按Esc退出后恢复完整控件。图片模态框内先由阅读器处理Esc，关闭图片后再退出全屏。全屏动作由runtime-kit-v1维护，底栏可见性和画布缩放由演示稿容器维护。

新增组件时，先实现并验证，再明确加入默认集合和 Agent 说明，不依靠目录扫描自动执行未知脚本。当前沿用两个运行时包即可，不为每个按钮建立插件框架。

## 当前能力与边界

| 组件 | 操作与验证重点 | 边界 |
| --- | --- | --- |
| 翻页、页码与进度 | 前后页、下拉跳转、首尾禁用、方向键、PageUp/Down、空格、Home/End | 输入控件和模态阅读器内不触发背景翻页；缺少备注或比例不禁用翻页 |
| 画布比例 | 自动、16:9、4:3、9:16 | 比例是首选尺寸，长内容自然增长；需要一页一纸时拆页并核验 PDF |
| 布局 | 自动、窄屏、平板、桌面 | 改变模板的布局状态，不模拟设备 viewport；比例与布局是独立维度 |
| 备注 | 随页更新、展开/收起、Esc 收起、正文可滚动至备注上方 | 展开时投屏也可见，随 HTML 交付；不提供独立讲者窗口 |
| 全屏 | 真实鼠标进入、Esc退出、外部状态同步、拒绝时显示反馈 | 演示稿全屏底栏持续隐藏；受浏览器 Fullscreen API 与权限限制，浏览器自身退出机制保留 |
| 保存 PDF | 每次点击调用一次打印入口，打印显示所有页并隐藏交互 | 打开系统打印对话框，用户选择另存为 PDF；不承诺自动下载，确定性文件使用 `html.pdf-export` |
| 原图阅读 | 适应窗口、原始尺寸、加减缩放、滚动/鼠标拖动、Esc、关闭后焦点返回 | 只接受同源 file/http/https；图片编辑、图库和外部图片抓取未实现 |
| 公式 | 本地 KaTeX、重复渲染幂等、失败保留 TeX | 公式内容由消费端核对；无引擎时明确降级 |

`data-source-min-width` 仍可指定原图初始阅读宽度；点“适应窗口”会恢复全图可见。缩放上限为原始尺寸的 8 倍且宽度不超过 48000 CSS px，下限允许大扫描图在手机上完整适配。图片缩放解除模板对 `max-width` 和 `max-inline-size` 的限制，避免百分比变化而图片不变。

## 维护与验收

- `runtime-kits/runtime-kit-v1/`：通用工具栏、模式状态、全屏、打印、公式；公开 `SuanhaiRuntime.init/setMode/renderMath`，初始化可重复。
- `runtime-kits/image-viewer-v1/`：独立模态阅读器；公开 `SuanhaiImageViewer.init/open`。
- `templates/containers/presentation-deck-v1/`：分页状态、比例、备注和控件组合；兼容预设的 `deck.js/deck.css` 必须同步。
- `tools/materialize/`：默认集合和本地资源装配；模板不硬编码运行时资源路径。
- `tools/viewport-check/`：真实产物的模式切换、全屏、翻页、备注、原图与缩放检查；系统打印对话框明确 `not-run`。
- `tests/test_html_interaction_controls.py`：在隔离目录复制真实资产，验证 320/390/768/1366/1920 宽度、正文避让、全屏真实手势、拒绝反馈、打印入口、原图缩放/拖动/错误恢复及可选控件隔离。

自动检查通过代表所记录的浏览器和视口下行为符合检查条件，不能代替审美认可、专业内容核对或系统打印对话框操作。当前没有跨浏览器完整兼容矩阵、独立讲者视图或完整无障碍自动验收。
