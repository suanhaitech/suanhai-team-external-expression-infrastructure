# 网页 HTML 能力目录

这里存放网页呈现形式下、以 HTML 为实现材料类型的共享基础设施。网页与文档、演示文稿等呈现形式在仓库顶层 `formats/` 下并列；HTML 不是模板的上层。

- `page-templates/`：可直接复制的完整 HTML 页面模板；
- `components/`：设计令牌、布局原语和语义组件包；
- `math/`：未来的离线公式包；
- `media/`：未来的本地媒体和图表包。

页面模板和通用组件都属于网页 HTML 内部的复用资产，但职责不同：页面模板负责完整页面组合，组件负责可复用的信息对象和视觉结构。Agent 先从 Manifest 找到完整能力包，再读取包内的 `package.yml` 和 `index.yml`。
