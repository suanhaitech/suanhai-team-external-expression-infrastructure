# 小组与项目上下文

这里承载理解小组和项目所需、经过来源管理的上下文。小组级上下文与项目级上下文分开保存，避免把一个项目误当成全组事实。

- `group/`：小组身份、职责与协作边界、表达边界、通用来源规则；
- `projects/README.md`：项目索引；可以暂时没有项目，也可以列出多个项目；
- `projects/_template/`：创建项目上下文时复制的空白文件，不是实际项目。
- `initialization.md`：初始化进度、未确认事项和下一步，供不同会话接续访谈。

新建仓库的上下文草稿应标记为“候选 / 待确认”，注明记录日期、来源和核对责任人。只有负责人逐项确认后，才能将状态改为“已确认”。冲突或缺少来源的内容保留为未知，不靠推断补齐。
