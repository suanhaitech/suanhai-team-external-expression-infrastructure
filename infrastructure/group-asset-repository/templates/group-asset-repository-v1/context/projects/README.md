# 项目上下文索引

一个小组可以没有项目，也可以并行参与多个项目。本索引只登记负责人确认纳入本资产仓范围的项目；每个项目拥有独立子目录，不把某个项目的事实提升为小组级事实。

| project-id | 项目名称 | 状态 | 项目上下文路径 | 负责人 | 最近核对 |
|---|---|---|---|---|---|
| 暂无已确认项目 | — | 空索引 | — | — | — |

新增项目时，复制 `_template/` 到一个稳定、简短、无个人信息的 `<project-id>/` 目录，补充来源和状态后再登记索引。初始化访谈尚未确认的项目可以放在待确认清单中，但不能登记为已确认项目。

`_template/` 是表单模板，绝不是项目事实或示例数据。
