# 小组内部可复用内容资产

`topics/` 保存经过来源、状态、适用范围和维护责任管理，且能够被本小组多次复用的内容资产，例如经核对的概念说明、常见问题或稳定的方法介绍。由本小组负责核实和更新；如果其他小组也可能感兴趣，并不会自动改变它的归属。

当某项经验确实跨多个小组适用时，可以从 topic 中提炼候选模式供基础设施评估。提炼时要去掉具体项目事实，说明适用条件、限制和验证依据；基础设施仓保存抽象后的模式、协议或工具，本目录仍由本小组维护原有事实和经验记录。不要让两边维护同一份事实。

它不等于任务产物目录，也不用于存放尚未评审的临时草稿。报告任务的各轮产物进入 `reports/`；系统性系列、课程和书籍仍归各自目录。每份 topic 应注明来源、状态、适用边界和最近核对日期；进入仓库或被复用都不自动构成发布授权。
