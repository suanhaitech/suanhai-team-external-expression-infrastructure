# 中性交接样例

本文件只展示填写结构，没有实际任务、用户认可或已运行检查。真实记录存入消费端，不回写到基础设施。

- 任务编号：由实际任务工具返回，此处未创建任务。
- 状态与操作版本：先用任务工具 `show` 读取 `task.json`，此处不复制状态。
- 最新作品：实际版本目录和摘要；当前样例没有生成作品。
- 续作基线：实际父仓 gitlink 与固定 submodule 完整 SHA；当前样例未指定。

| 范围 | 当前情况 | 续作动作 |
| --- | --- | --- |
| 已制作 | 尚无实际产物 | 读取完整页面计划后再制作 |
| 仅样式确认 | 尚无真实用户确认 | 不得把样例或局部反馈当作整稿验收 |
| 占位 | 页面计划的三页只是中性示例 | 在真实任务中明确占位原因与完成条件 |
| 已讨论未制作 | 这里不预填后续章节 | 有实际规划时登记，不冒充已有模板或已完成内容 |

当前认可范围：无；需要从真实任务事件核对用户原话和具体页面 ID。

当前检查：全部 `not-run`。后续应登记实际命令、结果、证据路径和限制，不能沿用此样例的日期或空摘要。

下次会话：读取仓库规则与固定 Manifest → `show` 任务 → 核对作品和摘要 → 复述已确认范围 → 按实际请求继续。用户已要求暂停且任务状态为 paused 时通过 `resume` 恢复；用户尚未要求暂停时不能仅因存在交接文件就改状态。

尚未授权的动作：没有从样例得到任何提交、推送、部署、发布或依赖升级授权。
