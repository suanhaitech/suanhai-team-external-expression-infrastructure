# Source Register v1

来源附录模板：保留资料名称、版本定位和获准引用范围，方便读者追溯依据。

- 插槽：`title`、`introduction`、`source-items`、`usage-boundary`
- 来源名称、日期和引用范围由消费端提供并核对；模板占位内容不是事实
- 资料过多时可以拆成多个附录页；窄屏使用纵向信息结构

各版本并列列出来源 ID、名称、版本/日期、定位、核验状态和使用边界，不用“最新版”静默合并。素材字节摘要由 `html.source-assets` 管理；来源索引不替代正文判断的就近来源定位，哈希正确也不证明专业结论或授权正确。核对跳转目标与原文位置，不能使用虚假的 `href="#"`。手机及打印保留完整材料名和定位。
