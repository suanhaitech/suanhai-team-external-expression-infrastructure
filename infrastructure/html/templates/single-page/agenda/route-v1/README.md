# Route Agenda v1

目录模板：按读者理解顺序列出章节及其要回答的问题。它是静态内容页，不含点击跳转或翻页交互。

- 插槽：`title`、`introduction`、`agenda-items`
- 列表项结构：章节编号、章节标题、问题说明、可选起始页码（`.sp-agenda-route__page`）
- 使用时按实际章节增删列表项；不要把目录做成另一套导航栏
- 资产来源：本仓原创 HTML/CSS；从出版物目录与演示稿路线页提取信息层次，未复制外部代码

目录样式可以先确定；章节名称、顺序和页码在正文稳定后回填。默认不生成链接，不与底部导航争夺阅读控制。删除起始页码元素也不影响章节槽。支持可选 `editorial-warm` 主题。

项目汇报按总体判断、工作线证据、跨线影响和确认/行动组织路线，时长可按会议预算注明，不按固定页数分配。插页/拆页后以稳定页面 ID 核对实际页序、目录页码和导航选项，不能保留只有章节封面却无正文的空章；手机与打印须保持顺序和页码可辨认。
