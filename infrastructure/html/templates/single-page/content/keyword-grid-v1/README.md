# 关键词判断网格

能力 ID：`html.single-page.content.keyword-grid-v1`。支持2–4项判断；首尾可按相同顺序复用，构成问题提出与总结呼应。不固定为某四个项目目标。

内容槽：`eyebrow`, `title`, `summary`, `keywords`, `boundary`。标题、来源、限定条件由消费端填充。示例文字和 SVG 仅演示结构，不表示项目事实。共享页框由 `shared_styles` 声明，颜色可选 `editorial-warm`。

支持可选 `supporting` 组件槽，由 page-plan 为本页绑定组件；不要求每页都插入组件。

手机自动单列、标题自然换行、长内容允许增高；桌面与打印应以真实内容重新检查。详细溯源可以放讲者备注，必要的事实限定、数据口径及图片来源仍须随内容保留。
