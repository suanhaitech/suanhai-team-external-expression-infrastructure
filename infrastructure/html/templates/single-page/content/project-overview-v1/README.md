# 项目总览 v1

能力 ID：`html.single-page.content.project-overview-v1`。

用于项目经理统一汇报的开场内容页：先给项目总体判断，再解释上期基线、本期变化及其对目标或里程碑的影响。它适合放在封面之后，后接各工作主线进展页；总览不替代主线的证据和专业核验。

- 插槽：`eyebrow`、`title`、`summary`、`period`、`cutoff`、`presenter`、`baseline`、`change`、`milestone-impact`、`workstreams`、`source`。
- `workstreams` 是可增删的主线摘要列表；每条保留结果、限制、项目作用及责任/来源。主线过多时拆页，不压缩字号。
- 周期、数据截止时间和来源版本需显式填写；首次汇报没有上期材料时，基线应说明真实起点。
- 不用未经核验的完成百分比表达整体进度；未收到更新不能写成无进展。
- 样式支持窄视口、容器宽度变化和打印，长内容自然增长；要求一页一纸时，消费端需拆页并检查真实导出结果。

本页面为原创结构，仅含中性占位符，不含项目事实。主汇报人负责整合、口径和跨线解释；各主线负责人核验本线事实和专业结论。页面无独立运行时，需通过 `html.materialize` 组合到已登记的 `paged-deck` 容器。
