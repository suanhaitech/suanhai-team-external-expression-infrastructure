# 当前结论与证据

能力ID：`html.single-page.content.conclusion-evidence-v1`。

一个主判断、互补证据入口及限制；适合工作主线的第二层讲述。`title` 直接写判断，`claims` 保留一个主张及其证据，`boundary` 写适用条件和尚未证明内容，`source` 写版本/截止时间与核验状态。

每个 `evidence.claim-source` article 表达一个判断，可在其对应证据区增加原生列表或多个证据段落。每条写来源 ID、版本、定位、证据内容与支持关系，保留首条原字段，新增条目不重复声明同名可填槽。不同主张拆页；证据条数服从论证，不固定四项。

中性写法：“已形成可进入接口评审的详细设计”；证据为职责、输入输出、异常路径和评审清单；边界是尚无实现测试。风险结论写触发条件/后果/核验动作，程序终止与独立质量验收分别举证。主证据是一张图时优先改用 `figure-analysis-v1`，不要把图片压缩成一条来源小字。

页面可独立使用或与其他单页自由组合，不限制工作主线数量、周期或总页数。数据列表由Agent在物料化后按真实内容增减；`page-plan.slots`仅允许纯文本，不通过HTML字符串注入复杂结构。

嵌入的组件展示沿用核心包契约；内部`data-field`只用于就地编辑，不是第二套可调用槽协议。需单独插入组件时使用supporting槽，避免与已有主体重复。

默认未知信息保留待确认，重要限制保持可见。主题可用editorial-green或editorial-warm，结构相同。桌面内容过多时拆页，不裁切或持续缩字；手机允许明确的滚动阅读，打印允许续页。
