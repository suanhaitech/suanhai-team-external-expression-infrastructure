# Method Content v1

方法正文模板：以“问题、方法、证据、判断”组织流程，适合架构说明、实验路径、验证方案和阶段计划。

- 插槽：`eyebrow`、`title`、`summary`、`steps`、`method-note`、`source`
- 默认四步可按实际方法增删，但每一步应说明输入或产出
- 公式可放在步骤说明中，公式运行时仍由 `html.runtime-kit-v1` 选配提供

步骤数量支持2–4项；宽容器显示顺序箭头，窄屏改纵向排列，保持编号顺序。各步以“短标题＋一句解释”表达；复杂分支或架构图应使用图像分析页，不把此模板扩成流程图编辑器。可选暖白主题。
