# 内容页模板

这里放置 `role: content` 的单页模板。指标、证据、对比、架构、方法和公式作为版式变体；每种内容页都应保留来源、口径或待确认状态的插槽。当前模板：[`evidence-v1`](evidence-v1/README.md)、[`method-v1`](method-v1/README.md)。

新增通用变体：[`stages-v1`](stages-v1/README.md)、[`observation-v1`](observation-v1/README.md)、[`definition-mapping-v1`](definition-mapping-v1/README.md)、[`comparison-v1`](comparison-v1/README.md)、[`figure-analysis-v1`](figure-analysis-v1/README.md)、[`keyword-grid-v1`](keyword-grid-v1/README.md)。这些版式可用于课程、技术讨论与项目沟通，场景画像决定各槽填什么内容。

| 项目沟通模板 | 表达职责 |
| --- | --- |
| [`project-overview-v1`](project-overview-v1/README.md) | 项目总体判断、周期变化与里程碑影响 |
| [`workstream-update-v1`](workstream-update-v1/README.md) | 单条主线的目标、结果、证据、限制和下周期结果；可重复组合 |
| [`dependencies-v1`](dependencies-v1/README.md) | 主线之间的输入输出关系、整体影响和双方协作请求 |
