# 跨线依赖与协作页

能力 ID：`html.single-page.content.dependencies-v1`。兼容 `paged-deck` 容器，状态为 `implemented / experimental`。

本页用于项目经理把各主线的结果连接成项目整体：上游交付什么、下游依赖什么、还缺少哪些衔接条件，以及它们如何影响下一里程碑。右侧承载需要双方确认或提供的具体输入，不承担正式方案评审或资源裁决。

- `title`、`summary`：本次最需要理解的项目影响和共同目标。
- `dependency-items`：可增删的依赖条目，包含输入输出关系、就绪状态、目标影响和解除条件；数量以实际依赖为准。
- `collaboration-items`：可增删的协作请求，包含请求内容、对接责任人、期望时间、状态和推进影响。
- `source`：来源版本、核对截止时间及仍待确认的范围。

没有已知依赖或请求时说明核对范围，或在内容计划中省略本页；不能为填版面虚构风险。主线负责人核验依赖事实，项目经理负责整体解释，发布范围仍单独确认。长条目拆成多页，窄屏转单栏，保留全文和来源，不通过裁剪凑画布比例。

通过 `html.materialize` 的 `--page-id` 组合，不传 `--component-id`。同一模板可重复出现，工具负责重写页面内 ID 和页码。所有占位内容仅用于说明结构，不代表真实项目状态。
