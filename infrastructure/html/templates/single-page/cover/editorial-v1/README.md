# Editorial Cover v1

封面模板：用主题和一句核心判断建立阅读预期，组织信息置于上沿，读者与日期作为辅助元信息。

- 插槽：`organization`、`date`、`scenario`、`title`、`summary`、`audience`、`thesis`
- 适用：阶段沟通、技术报告、项目说明
- 不适用：把目录、完整背景或未经确认的项目结论塞进封面
- 兼容容器族：`paged-deck`、`continuous-scroll`
- 资产来源：本仓原创 HTML/CSS；布局参考采样记录中的出版物式标题层级，不复制外部代码或图像

项目汇报需交代受众、周期/数据截止点和沟通目的，主讲人与文档状态按实际任务呈现；没有核验的结论不放封面。开场总体判断可由后续总览页承载，不为固定“三句话”新增页面。核对合作方名称、符号、日期与正文范围一致，长标题在手机和打印完整可读。
