# 插图型技术出版封面

能力 ID：`html.single-page.cover.technical-editorial-v1`。保留主题、副标题、引导问题、可选本地插图和轻量署名。标题可保留语义片段，也可直接替换为连续文本。

内容槽：`event`, `title`, `subtitle`, `question`, `illustration`, `organization`, `presenter`, `date`, `source`。标题、来源、限定条件由消费端填充。示例文字和 SVG 仅演示结构，不表示项目事实。共享页框由 `shared_styles` 声明，颜色可选 `editorial-warm`。

手机自动单列、标题自然换行、长内容允许增高；桌面与打印应以真实内容重新检查。详细溯源可以放讲者备注，必要的事实限定、数据口径及图片来源仍须随内容保留。
