# Presentation Deck Container v1

能力 ID：`html.container.presentation-deck-v1`

这是一个只定义阅读方式的逐页容器。它负责页面比例、底部页码选择、上一页/下一页、键盘翻页、讲者备注和逐页打印；具体页面由 `--page-id` 按命令行出现顺序组合。页面 CSS 会作为本地资源复制到作品目录。

容器不内置演示内容。脚本不可用时，浏览器按文档顺序显示所有页面；启动脚本后才启用单页切换。输出不依赖网络服务或 CDN。

## 全屏演示（1.2.2）

进入全屏后，底部控制栏持续隐藏，鼠标移到下沿、触摸下沿或Tab均不会唤出，也不能聚焦隐藏控件；已打开的讲者备注收起。按Esc退出全屏后恢复普通窗口的完整控制栏。方向键、PageUp/Down、空格和Home/End仍可翻页；在图片模态阅读器内，Esc先关闭图片，再按Esc退出全屏。浏览器自身的退出机制继续有效。

桌面整页等比放大并使用完整视口，指针移动不改变倍率或页码位置。手机保留窄屏与页内滚动。更换布局、比例、备注或保存PDF时，先退出全屏。此行为由容器与共享运行时共同提供；升级后需重新物料化作品中的deck.css、deck.js及runtime-kit-v1，单独更新gitlink不会改变旧作品。

## 组合页框修正（1.2.1）

组合 `data-single-page-role` 单页时，容器统一画布尺寸与页码，单页负责背景、内部留白和内容布局。容器不再叠加白色边框、封面顶边或第二层内边距。当前比例下各逻辑页使用同一画布高度；页码从模板页脚移到画布底部的独立行，所有页保持共同基线。该行继承单页背景和文字色，深色过渡页也适用。正文单页在剩余区域内滚动，页码不覆盖最后一行。

普通窗口和桌面全屏均保留以上关系；普通窗口展开备注时阅读区同步缩短，手机全屏隐藏控制栏并使用完整高度，内容仍可滚到末尾。需要滚动的内容仍由 viewport-check 报告为纵向溢出，不等同于适合投屏。打印解除固定画布与内部滚动，展开完整内容；旧预设中没有嵌入单页的原生页面保留原页框。

升级后应在新版本重新物料化，移除消费端复制的页框、页码和全屏覆盖，再核对实际截图；不要同时保留两套 folio 实现。内容密度与图文比例的消费端定制需单独评审，不要求一并删除。共享修复不会改写旧版本。

组合页命名为 `deck-page` 尺寸容器，公共页框及单页模板可以按设计画布高度收紧留白、调整图文分配。短窗口至少检查 1280×650 与 1000×700，再从短窗口进入全屏检查同一组页面。全屏不会自动消除原画布的内容超高；字体、正文和配图必须在进入全屏前就能正确布局。窄画布或真实超量内容继续保留滚动及失败记录。

## 交互更新（1.1.0）

消费端升级与版本化修订步骤见 [演示稿安全区测试](../../../../../docs/html-presentation-safe-area-test.md)。

比例、备注与默认运行时在底部控制栏统一呈现；画布按实测控件高度限制在控制栏上方，展开备注时也会为备注面板留出空间，内容过高时在当前页内滚动，不会被固定控件覆盖。小屏保留文字与 44px 高度。viewport-check 会将需要页内滚动才能读完的页面报告为纵向溢出，供制作者调整内容密度。缺少备注或比例不影响翻页。展开的备注在投屏中也可见，打印隐藏。详见 [交互组件](../../../../../docs/html-interaction-components.md) 与 [体验页](../../../runtime-kits/preview/index.html)。

桌面全屏会把当前页面盒子作为一个整体，按进入前的宽高比等比放大并居中；整页背景、内容和页码保持同一构图。当前全屏控制栏持续隐藏，按Esc退出。手机使用窄屏布局，不套用桌面等比缩放。页面和单页样式中的视口相关尺寸应基于页面容器（`cqw`）定义，避免全屏后视口单位变化造成字号与留白跳变。
