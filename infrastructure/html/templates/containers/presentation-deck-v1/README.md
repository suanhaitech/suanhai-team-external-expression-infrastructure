# Presentation Deck Container v1

能力 ID：`html.container.presentation-deck-v1`

这是一个只定义阅读方式的逐页容器。它负责页面比例、底部页码选择、上一页/下一页、键盘翻页、讲者备注和逐页打印；具体页面由 `--page-id` 按命令行出现顺序组合。页面 CSS 会作为本地资源复制到作品目录。

容器不内置演示内容。脚本不可用时，浏览器按文档顺序显示所有页面；启动脚本后才启用单页切换。输出不依赖网络服务或 CDN。

## 交互更新（1.1.0）

消费端升级与版本化修订步骤见 [演示稿安全区测试](../../../../../docs/html-presentation-safe-area-test.md)。

比例、备注与默认运行时在底部控制栏统一呈现；画布按实测控件高度限制在控制栏上方，展开备注时也会为备注面板留出空间，内容过高时在当前页内滚动，不会被固定控件覆盖。小屏保留文字与 44px 高度。viewport-check 会将需要页内滚动才能读完的页面报告为纵向溢出，供制作者调整内容密度。缺少备注或比例不影响翻页。展开的备注在投屏中也可见，打印隐藏。详见 [交互组件](../../../../../docs/html-interaction-components.md) 与 [体验页](../../../runtime-kits/preview/index.html)。
