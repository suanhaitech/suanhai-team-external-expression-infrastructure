# HTML Presentation Deck v1

能力 ID：`html.presentation-deck-v1`

这是面向现场讲解和阶段沟通的多页 HTML 演示稿模板。它与长页滚动的 `html.project-report-v1` 分开维护，避免把报告页的顶部章节导航误当成演示稿翻页控件。

## 结构与交互

- 每个带 `data-deck-page` 的 `section` 是一页；可以按任务需要增加、删除或重排页面。
- 页面切换固定在底部：上一页、页码选择、下一页和进度提示；首尾按钮会禁用。
- 方向键、Page Up/Page Down、Home 和 End 可翻页。焦点位于表单控件、链接或可编辑内容时，不截获按键。
- 自动比例在横屏优先使用 16:9，在竖屏优先使用 4:5；比例菜单也允许手动选择 16:9、4:3 或 9:16。比例是画布的首选尺寸，窄画布会转为单栏，内容较长时允许自然增长，保证文字不会被缩小或裁掉。
- 可选的运行时包会补充显示模式、全屏和浏览器打印入口；这与页码导航互不替代。
- 桌面全屏将当前页面整体按进入前的尺寸等比放大、居中；控制栏默认收起，指针移至屏幕下沿或键盘焦点进入控制栏时显示，并按剩余高度重新缩放页面。手机保留窄屏排版。
- 1.2.1 在手机全屏底栏唤出时缩短阅读区；组合单页的无重复页框与固定页码规则见 [容器说明](../../containers/presentation-deck-v1/README.md)。本预设原生页面保留既有页框。
- “演讲备注”按当前页显示独立备注，不会把长说明挤进主画面。
  备注是 HTML 交付文件的一部分，读者可以查看；仅可放入获准随页面交付的说明，不能存放保密材料或内部凭据。
- 打印时显示全部页面，每个逻辑页从新纸页开始并隐藏屏幕工具栏。内容过长时保留全部文字并允许续页；需要严格一页一纸时，制作阶段必须拆分过长页面，并检查实际导出 PDF。

脚本未运行时，页面会按长文档方式依次显示，所有内容仍可阅读；翻页、比例和备注控件保持隐藏，不留下失效按钮。模板不依赖 CDN、远程字体、远程图片或服务端。

## 使用

1. 通过 `html.materialize` 选择 `html.presentation-deck-v1`，按需要选择语义组件、响应式布局包和 `html.runtime-kit-v1`。
2. 在消费端复制出的 `index.html` 中替换 `data-slot` 占位内容；事实、图表数据、来源和使用授权仍由消费端提供并确认。
3. 每页保留一个核心判断，并在页脚补充来源与数据日期；过长的证据、术语或方法细节移到后页或附录。
4. 增删页面时，为每页保留唯一的 `id`、`data-deck-page` 和 `data-page-title`；页码菜单由脚本自动生成。
   语义组件初始装配到第二页的插槽；选择多项组件后，应按各页主题分配到对应页面，避免把所有组件堆在一页。屏幕工具栏和页脚页码随页数重新计算；禁用脚本时的静态页脚编号需一并更新。
5. 运行 HTML 静态检查和多视口预览；需要 PDF 时，再由负责人确认打印范围和参数。

## 资产来源

本模板的 HTML、CSS 与 JavaScript 为本仓库原创，没有复制用户提供的项目页面、图片、实验数据或项目事实，也不含第三方运行资源。离线公式、全屏和浏览器打印按钮由被选中的运行时包提供，不会自动安装到所有页面。

## 交互更新（1.1.0）

比例、备注与默认运行时在底部控制栏统一呈现；实测控件高度预留正文空间，小屏保留文字与 44px 高度。缺少备注或比例不影响翻页。展开的备注在投屏中也可见，打印隐藏。详见 [交互组件](../../../../../docs/html-interaction-components.md) 与 [体验页](../../../runtime-kits/preview/index.html)。
