# 演示页公共页框与字阶

`html.presentation-foundation-v1` 提供 `.ex-page` 页框、`.ex-page__header`、`__eyebrow`、`__title`、`__lead`、`__body`、`__footer` 和 `__supporting`。新单页通过 `shared_styles` 声明依赖，物料化时随作品复制；它不承担场景内容和页面翻页。

颜色使用 `--ex-*` 主题令牌，可选择组件包中的 `editorial-warm` 暖白主题；不选择时使用中性浅色。标题自然换行，手机保留可读字号并自然增高。禁止通过缩小整页、裁切或隐藏正文凑比例。已有响应式布局包继续负责全局长宽比与安全溢出。

这是页框与排版规则，不是整套课程；项目名称、人物、原文图像与结论属于消费端。

1.0.1 支持演示容器命名的 `deck-page` 高度查询：宽度大于 760px、高度不超过 560px 的设计画布收紧页边距及标题、页脚留白，保持文字字号。图解、定义映射与技术封面各自在模板样式中调整自身布局；全屏等比缩放沿用同一设计坐标，不因屏幕变大重新排版。窄画布保留阅读滚动，内容过多时仍报告溢出。
