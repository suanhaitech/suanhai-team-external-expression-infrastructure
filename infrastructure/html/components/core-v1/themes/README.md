# 主题层

主题只覆盖设计令牌，不复制或修改语义组件结构。未来可增加 `technical-dark.css`、`high-contrast.css` 等主题；主题必须声明对比度、打印和减少动画行为。

## 浅绿主题 editorial-green

浅绿纸底、深绿正文与强调，使用`--theme editorial-green`或在组件总样式后加载editorial-green.css。原有成功/警告/危险语义色保留；状态始终有文字。没有动画，沿用组件减少动态效果约定；打印加深正文与辅助文字。正文和辅助文字需满足WCAG AA 4.5:1，装饰线不作为状态唯一标识。自动对比度检查仅覆盖主题文字配对，不能替代完整无障碍评审。
